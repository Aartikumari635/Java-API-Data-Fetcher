# API Data Fetcher

A Java Swing application that fetches random jokes from a public REST API and displays them in a user-friendly graphical interface.

## Features
- Fetches live data from a public API
- Parses JSON responses
- Displays jokes in a readable format
- Handles network and API errors
- Provides a Clear button

## Technologies
- Java 11+
- Java Swing
- Java HTTP Client
- REST API
- JSON parsing

## How to Run
Open the project in NetBeans, build it, and run `APIDataFetcher.java`.

## API
Official Joke API: https://official-joke-api.appspot.com/random_joke
